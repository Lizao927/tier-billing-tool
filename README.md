# 多等级阶梯计费工具（Windows EXE）

这是一个通过 GitHub Actions 在 Windows 云端自动编译的项目。**最终生成的 EXE 不要求使用者安装 Python**。

## 如何通过 GitHub 生成 EXE

### 1. 创建仓库
1. 登录 GitHub。
2. 点击右上角 `+` → `New repository`。
3. Repository name 可填写 `tier-billing-tool`。
4. 选择 `Public` 或 `Private` 均可。
5. 点击 `Create repository`。

### 2. 上传本项目文件
将本 ZIP 解压。把解压后的所有内容（包括 `.github` 隐藏文件夹）上传到刚创建的仓库根目录。
建议使用 GitHub 网页：
1. 在仓库首页点击 `Add file` → `Upload files`。
2. 拖入项目内的文件和 `.github/workflows/build-windows.yml`。
3. 点击 `Commit changes`。

如果网页上传不便，可使用 GitHub Desktop 上传整个文件夹。

### 3. 等待 Windows 云端编译
1. 打开仓库的 `Actions` 页面。
2. 选择 `Build Windows EXE` 工作流。
3. 等待运行状态变成绿色成功（通常几分钟）。
4. 点击最新一次运行记录。
5. 页面底部 `Artifacts` 区域下载 `多等级阶梯计费工具-Windows-x64`。

### 4. 使用 EXE
1. 解压下载的 ZIP。
2. 双击 `多等级阶梯计费工具.exe`。
3. 不需要安装 Python，不需要运行命令或 BAT。

## 功能
- 选择企业级、商业级、尊享级。
- 输入账单月份数（例如1—11月输入11）。
- 选择 Excel 工作表。
- 支持 .xlsx / .xlsm。
- 按产品类型包含匹配黑名单关键词，忽略大小写及空格。
- 在 GUI 中增加、修改、删除黑名单关键词。
- 可将黑名单配置保存为 JSON，下次启动自动加载。
- 导出包含计费汇总、消费明细、计费规则的 Excel。

## 阶梯规则

- 企业级：月保底55,000；0–550,000部分10%；550,000–1,800,000部分7%；1,800,000–3,300,000部分5%；超过3,300,000部分3%。
- 商业级：月保底28,000；0–280,000部分10%；280,000–900,000部分7%；900,000–1,650,000部分5%；超过1,650,000部分3%。
- 尊享级：月保底300,000；0–8,000,000部分10%；8,000,000–25,000,000部分6%；超过25,000,000部分5%。

先过滤黑名单，再按折前官网价汇总；月均消费=过滤后总额/月份数。
月度应收=MAX(月均阶梯费,月保底价)；账期应收=月度应收×月份数。

## 默认黑名单
- AI Infra智算规划设计与实施服务
- AI平台辅助运营服务
- AI平台开发与实施服务
- AI平台运维与保障服务
- AI平台咨询与规划服务
- AI使能服务优化与提升服务
- 支持计划

注意：输入账单第一行需有“产品类型”和“官网价(¥)”字段。旧版 .xls 不支持，请先另存为 .xlsx。
